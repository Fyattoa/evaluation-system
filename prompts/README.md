# 评估 Prompt 模板

本目录包含用于 RAG 评估的 LLM prompt 模板，可直接导入 Dify 或其他支持的工作流中使用。

## 文件说明

| 文件 | 用途 | 适用场景 |
|------|------|----------|
| `llm_answer_eval.txt` | 评估 LLM 生成答案的质量（相关性、完整性、准确性、忠实度） | 对比不同 LLM 或不同 prompt 的输出效果 |
| `retrieval_general.txt` | 评估通用分块模式下的知识库召回质量（含两级完整性） | 通用模式知识库的召回效果评估，无历史信息 |
| `retrieval_parent_child.txt` | 评估父子分块模式下的知识库召回质量（子段+父段合并） | 父子模式知识库的召回效果评估，无历史信息 |
| `retrieval_general_info.txt` | 带历史信息的通用模式召回评估 | 需要结合历史实验数据判断当前配置是否最优 |
| `retrieval_parent_child_info.txt` | 带历史信息的父子模式召回评估 | 需要结合历史实验数据判断当前配置是否最优 |

## 使用方式

1. 将对应 prompt 文件内容复制到 Dify 的 LLM 节点的 **SYSTEM** 提示框中。
2. 根据 prompt 中的输入说明，传入原文档、召回结果或生成答案等变量。
3. 运行工作流，获取 JSON 格式的评估结果。

## 注意事项

- 所有 prompt 均采用 1-10 分制，禁止打 10 分（除非完美到不可能）。
- 完整性评分需提前列出关键信息点清单。
- 带历史信息的 prompt 需要在输入中额外提供历史实验记录和当前参数。
